Sound & motion

No audio files were found on this server, so the overlay is silent. Run scripts/fetch-audio.sh (GitHub clone) or use the Drive package, which ships the audio files directly, then restart the server.

Each game has its own calm background loop; effects play when someone arrives, a gift lands, a scene beat is reached, or a command is used. Browsers start sound only after interaction, so click anywhere in the browser source once during rehearsal — the overlay retries on every event. The operating system's reduced-motion preference is honored automatically.

Event source

Live feed is UNVERIFIED: it has never been tested against a real TikTok LIVE session. It is read-only and needs only the public username. Signing for the live feed goes through Euler Stream, a third-party service: if it is down, rate-limited, or changes, the feed stops. Never paste cookies or tokens anywhere — this game has no place to paste them, by design.

Scene controls

The kill-switch stops event intake too, not just the picture. Resume restarts intake. Reset clears spots, the meter, and the local snapshot.

Simulator

Fake events for rehearsal. They behave exactly like live events (same filters, cooldowns, and queue).

Manual / mod triggers

Drive the game by hand — the fallback path that needs no TikTok connection. A moderator at this machine can welcome people and trigger scenes live.

Recent activity

Counts and filtered names only. Comment text and viewer ids are never shown here.

On-screen wording

Commands and gift effects are fixed per game and listed in the README. If any wording on screen ever asks viewers to follow, gift, or tap, that is a bug — stop the game and report it.
